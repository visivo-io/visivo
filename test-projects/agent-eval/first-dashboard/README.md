# agent-eval/first-dashboard

An agent-eval project with no sources. Each prompt in `scripts/agent_eval/datasets/first-dashboard/prompts.yml` adds the one source that the onboarding import or connection would add, then asks for a first dashboard. Build the files and databases under `data/` with `python scripts/agent_eval/datasets/first-dashboard/seed.py` (see `scripts/agent_eval/README.md`).
